# انبارگردانی – مدیریت هوشمند انبار

## فایل اکسل ورودی (xlsx)
ردیف اول عنوان ستون‌ها؛ عنوان‌ها خودکار تشخیص داده می‌شوند:
«نام کالا» (اجباری)، «موجودی سیستم» (اجباری)، «کد کالا» (کد دارو، اختیاری)،
«بارکد» (اختیاری؛ برای چند بارکد، آن‌ها را با Enter، فاصله، ویرگول یا «،» جدا کنید)،
«شکل دارویی» (اختیاری)، «دسته» (اختیاری).
نمونه: `قالب-ورود-اکسل.xlsx`

## امکانات
- خانه: پیشرفت بر اساس دسته‌های انتخابی، آمار و فهرست «نیاز به اقدام».
- کالاها: افزودن دستی کالا (نام، کد، چند بارکد)، جستجو، فیلتر و ترتیب (دسته، شکل دارویی، وضعیت)، اسکن بارکد.
- ثبت موجودی: شمارش اول و مجدد، دکمه‌های سریع، اسکن و ثبت پیوسته.
- گزارش کسری و اضافه، خروجی Excel و PDF فارسی، چاپ مستقیم.
- بایگانی دوره‌ها و مرور ماه‌های قبل.
- انتقال مستقیم اطلاعات بین دو گوشی (Wi‑Fi یا Hotspot) یا با فایل.
- حالت تاریک خودکار.

## ساخت APK با GitHub Actions
محتویات را push کنید، از تب Actions فایل `Anbargardani-debug-apk` را از Artifacts دانلود کنید.
